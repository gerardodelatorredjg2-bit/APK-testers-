## What this means for the 100–200 MB target
The target is aggressive: audio, images and models alone account for about 648.9 MiB before scenes and code. Reaching 100–200 MB while keeping the complete game offline will require measured lossy audio/texture reduction, mesh optimization, removal of genuinely unused resources and possibly optional downloadable content. We will measure an actual APK before deciding which compromises are necessary. No minigame or asset will be removed solely because it is large.
